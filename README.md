# Bookify
Bookify-Book Management System
Bookify is a simple Spring Boot CRUD (Create, Read, Update, Delete) web application that allows users to manage a collection of books.
It demonstrates basic Spring MVC, Spring Data JPA, and Thymeleaf integration for beginners learning Spring Boot development

🚀 Features
➕ Add New Books
📖 View All Books
✏️ Update Existing Books
❌ Delete Books

🧠 Tech Stack
-----------------------------------------------------------------------
| Layer                 | Technologies                                |
| :-------------------- | :------------------------------------------ |
| **Backend Framework** | Spring Boot                                 |
| **View Layer**        | Thymeleaf, HTML, CSS                        |
| **Database**          | MySQL                                       |
| **ORM**               | Spring Data JPA (Hibernate)                 |
| **Build Tool**        | Maven                                       |
| **IDE**               | Spring Tool Suite / IntelliJ IDEA / Eclipse |
-----------------------------------------------------------------------
